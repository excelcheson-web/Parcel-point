# Parcel Point

Parcel Point is a premium logistics portal built with Next.js. It includes a public logistics website, shipment tracking, an admin dashboard, receipt generation, waybill workflows, and Firebase-backed data features.

## Getting Started

Install dependencies:

```bash
npm install
```

Create `.env.local` from `.env.example`, then add your Firebase project values.

Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
